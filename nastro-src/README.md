# Nastro – sources

The `.pd` files in `../Nastro` are generated by these scripts. Edit the scripts, not the `.pd` files.

    python3 gen.py ../Nastro                 # regenerate the whole patch (main.pd + modules)
    python3 gensim.py ../Nastro              # regenerate mac-sim.pd (Mac simulator)
    python3 makekit.py ../Nastro/drums.wav   # regenerate the drum kit

`gen.py` runs the other `gen*.py` (tape, screen, mix, tempo, drum, tapemap, synth, seq, smpl, proj, tapeedit,
tomb, rev, meter, endl, mirror, album, arp). The `apply_*.py` scripts are the history of changes already applied to the
generators (each keeps a `*.pre-<name>` backup when it runs).

Target: Organelle 1, OS 4.0, Pd 0.49, single-core ARM, Pd started with `-audiobuf 6`.
Rules learned on the device: avoid control-rate bursts longer than ~2 ms per block (split long loops across
scheduler ticks), redraw the OLED only when something changes, keep the OLED under a few hundred messages/s.

## Review tools
- `python3 review.py ../Nastro`: sends/receives without a counterpart, connections into `[r]`, `[delay]` fed with
  floats, `expr` functions missing in Pd 0.49, orphan objects, signal objects per patch.
- `python3 review_order.py ../Nastro`: outlets feeding a cold inlet and a hot path that reaches it (order bugs).
- `python3 errscan.py test_X.py`: runs a test and reports every unexpected Pd error.

**Pd pitfalls met so far**
- Pd 0.49 `expr` has no `mtof()` (convert with the `[mtof]` object first). Available functions: the `ex_*`
  names in the device binary.
- A multi-outlet `expr` evaluates each outlet only when it sends it (right to left): if one outlet writes a table
  the others read, collect everything in a `[pack]` first and write afterwards.
- `[r name]` has no inlet: to merge two receives, connect both to the destination.
- A float into the left inlet of `[delay]` sets its time and starts it.
- Commas in comments (`#X text`) break the patch.

## Tape
- 4 tracks x 60 s, precise playhead (`rpole~` counter + per-block integer onset).
- Loop wrap crossfade: a second head per track keeps playing past the jump and fades out in 5 ms while the main
  head fades in (`apply_xfade.py`, `test_loopclick.py`). Only the output is crossfaded; overdub reads the main head.
- Loop recording seam fix (`apply_loopseam.py`, `test_loopseam.py`): the wrap is handled per 64-sample block, so
  each pass wrote up to 65 samples past the loop end and left a seam at the loop start. While recording a loop,
  the samples written past the end are moved to the start (re-mixed for overdub) and the area after the end is
  restored from a copy saved when recording starts / the loop end moves.
- Punch-in/out fades (`apply_punchfade.py`, `test_punch.py`): the writer blends old → new over 8 ms at rec start
  and back at rec stop, and keeps running until the fade-out is done, so punches leave no step on tape. The gain
  of the last block is kept in `pgbuf` so the seam fix stays exact when a fade crosses the loop end.
- Key timing on the device (`apply_keydefer.py`, `test_devorder.py`): the Organelle delivers keys after a DSP tick
  but before that tick's `[bang~]` updates the tape position, so rec started the writer one block behind the
  head (a 64-sample silent gap at every restart). Tape keys, footswitch, navigation and track changes now go
  through `[pipe 0]`, which runs them after the position update. Mac batch tests can't reproduce the device order.
- Per-track FX sends (`apply_sends.py`, `test_sends.py`): each track's (L+R)/2 after filter and pan (the old mono FX
  feed) x a delay send and a reverb send (`line~`, default 1) -> `throw~ fxd-tape` / `fxr-tape`. Master: delay <-
  `fxd-tape`, reverb <- `fxr-tape` + delay out; DLY / REV stay the overall amounts. Live synth, drums and the input
  monitor stay dry (`apply_fxtapeonly.py`). MIX page 5 SEND; knob contexts 27 / 28 (`pkval` 116).
- OLED text types (`apply_oledtypes.py`): `Patch.msg` rebuilds every gPrintln type string (packOSC drops a text
  with more words than types and prints a number in an `s` field as "1.000000"); `$n` keep the hand-given type.
  `oled-sim.py` mimics all three device behaviours.
- Reverb freeze, AUX + G5 toggle (`apply_freeze.py`, `test_freeze.py`): input gain to 0 (50 ms `line~` before the
  pre-delay), every FDN line gain to 0.3535 (just under 1/sqrt(8): lossless Hadamard, no growth), damping `lop~`s
  to 20 kHz (pass-through). DEC / TONE are gated while frozen and re-applied on release; the reverb `switch~` stays
  on (also with REV at 0). LED white (7) while frozen, `FRZ` badge on FX / REVERB; `nst-load` releases it.
- Track DJ filter, no zipper (`apply_filterxfade.py`, `test_filtersweep.py`): `biquad~` (direct form II) clicks
  for a sample whenever its coefficients change while audio runs. Each track has two `biquad~`s: new coefficients
  go to the silent one and a 5 ms crossfade moves to it; while a knob turns, updates follow at most every 6 ms and
  the latest value is always applied. Resonance defaults to 0 (`apply_resdefault.py`).
- Sample-accurate wrap (`apply_xfadeauto.py`): just before the head reaches a loop edge each track is checked. If
  the loop start continues the audio at the end (recorded in loop mode), its read index wraps per sample
  (`expr~` offset) with no crossfade; otherwise it reads past the end and crossfades as before. The 3 samples
  `tabread4~` reads across the edge are temporarily replaced with the continuation and restored after the wrap.
  The tape editor and this guard must not overlap (`apply_guardedit.py`, `test_guardedit.py`): a DUPLICATE that
  copied the loop to hi.. while the guard was on got its first 3 samples overwritten by the guard's restore (a
  click at every restart of the duplicated loop, found in a saved project). An edit now restores the guard first
  (`tp-guard-restore`) and the guard stays off while the editor is busy (`[v tebusy]`).
- Loop from the keys (`apply_loopstart.py`, `test_loopstart.py`): the start (1st AUX+G#) went into the cold inlet
  of an [f] that was never banged, so every key-made loop started at 0 (since the first version).
- Lanes under the reels update 4x/s while recording (was 10x/s with a full rebuild each time). The rebuild runs in
  32 chunks of 8 iterations, ~1 ms apart (`apply_lanechunks.py`): recording with the TAPE page shown no longer makes
  block-long control bursts (slowest blocks 128 -> 65 us on the Mac, `test_reccost.py`). Pitfall fixed on the way:
  the chunk counter went into `[delay 1]` as a float, which sets the delay time.
- Speed, knob 1 in TAPE: 9 steps (-2 -1 -0.5 -0.25 0 0.25 0.5 1 2, `apply_speed025.py`) spread over the knob travel; with AUX held it is
  continuous (-2..2, magnets at 1 / 0 / -1). Global for all tracks.
- Recording at 0.25x / 0.5x / 2x (`apply_varirec.py`, `apply_speed025.py`, `test_varirec.py`): the rec factor is
  frozen at rec start (0.25, 0.5 or 2 if the speed is on that step, else 1x as before). They use `tape-vw.pd`, a
  writer in a resampled `[switch~ 128 1 2]` / `[switch~ 32 1 0.5]` / `[switch~ 16 1 0.25]` (DSP on only while writing) that reads the old tape at its own write
  index (overdub, punch fades as at 1x). 4-pole Butterworth low-passes feed the 0.5x (9.5 kHz) and
  0.25x (4.5 kHz) writers (anti-aliasing). Seam fix: overshoot up to 128 samples at 2x (`seamsave` 130), fade gain looked up per sample.

### Tape editing (`gentapeedit.py` → `tapeedit.pd`)
Encoder press in TAPE → menu `EDIT-T n`: CUT, COPY, PASTE, REVERSE, CLEAR, DUPLICATE, UNDO on the selected track,
over the loop region (when looping) or the current bar. Copies run 4096 samples per tick (`array get/set`, the
table name goes to the right inlet: Pd 0.49 has no `set` message). Reverse runs in real time with an `rpole~`
counter + `tabwrite~` (block-aligned; `vline~` was ~80 samples off).
- UNDO: before every change the touched region is copied into `te-undo`; UNDO swaps it with the tape (again =
  redo). Recording or loading a project forgets it (`apply_undo.py`).
- All tracks: menu item "MODE: 1 TRACK / ALL" (op 8). With ALL every op 1..6 runs for tracks 1..4 in sequence
  (state in table `teseq`), reusing the single-track code: clipboard and undo have 4 slots (offset
  (k-1)*length), the region is computed once, DUPLICATE moves the loop only after the last track
  (`apply_editall.py`, `apply_editall_menu.py`, `test_editall.py`).

## Synth engines
FM, SUB, PLUK, PAD, SMPL, AIR, GLASS, WAVE, STRING, ORGAN, DRONE, PIANO, MALLET. AUX+C again in SYNTH = next engine. Every voice switches its own DSP on at
a note and off when its sound has ended (`switch~`, PLUK `switch~ 16`; `apply_voiceswitch.py`): about -42% DSP idle.
- SUB ADSR (`apply_subadsr.py`, `test_subadsr.py`): AUX + knobs 2..4 on SUB = ATTACK (1–3000 ms), DECAY/RELEASE
  (10–5000 ms), SUSTAIN; knob 1 stays the synth volume. Amp ADSR (`vline~`), filter envelope attack + decay to 0.
  Defaults = the old sound (5 ms / ~400 ms / 100 %). Pickup ctx 13 slots 2..4.
- AIR (`apply_ambient.py`): noise through 2 band-passes (note + octave, `vcf~`), Q from breath (2) to whistle (60)
  with sqrt(Q) make-up gain, slow random LFO per voice on pitch and level. Knobs ATK REL Q MOVE (pickup ctx 18).
- GLASS: 4 partials (harmonic 1 2 3 4 <-> bell 1 2.76 5.4 8.93), shorter decay for higher partials, 2 detuned
  twins for beating, 6 voices, rings through note-off. Knobs DECAY BRITE INHAR BEAT (ctx 19). `test_ambient.py`.
- WAVE / STRING / ORGAN / DRONE (`apply_moresynth.py`, `test_moresynth.py`), knob contexts 23..26:
  - WAVE: sine -> `cos~` wavefolder (fold = FOLD x (1 + ENV x attack envelope), SYM offset adds even harmonics),
    `hip~` DC block, make-up gain for small folds.
  - STRING: Karplus-Strong (`switch~ 16`, `delwrite~`/`vd~` per voice), pick-position comb on the excitation, DAMP
    = loop low-pass (6x..60x the note), 6 s T60 while held, REL shortens it after note-off, 3 fixed body `bp~`.
  - ORGAN: drawbars 16' 8' 4' 2 2/3' (0..8 steps, squared), 4 ms key click (high-passed noise), leslie = slow
    vibrato + tremolo with its own rate per voice, 4 ms / 60 ms gate.
  - DRONE: two `phasor~` saws detuned +-DET/2 cents, each drifting (own slow LFO, up to +-15 cents), `vcf~`
    low-pass that breathes, squared envelope, attack = REL / 2 (0.5..15 s release).
- PIANO, engine 11 (`apply_piano.py`, `test_piano.py`): modal synthesis ported from the felt piano of the
  minichord-kalimba firmware. Per voice 7 two-pole resonators ([biquad~] fb1 = 2 r cos w, fb2 = -r^2, ff1 = gain,
  r = exp(-ln 1000 / (T60 sr))) struck by a half-sine pulse (vline~ ramp -> cos~ of ramp/2 - 1/4); FELT = pulse
  length, the fundamental's level compensated (|cos(pi x/2) / (1 - x^2)|, x = 2 f T); contact click; each strike
  0..6 ms late at random. Damping re-sends the coefficients with T60 = 0.15 s (gains unchanged: no click in Pd's
  direct form II). DSP per voice off when damped or silent (own timer, not voice_switch: the pedal sustains past
  the note-off). piano-post.pd, before the engine's clip: body (bp~ 110 Hz Q 1.5), sympathetic resonance (4
  combs, pedal down), pedal noises, LOFI = high cut + wow + hiss following the playing (no saturation: it
  sounded like clipping), soft limiter above 0.6. Footswitch = pedal while mode 0 and engine 11 (gentape.py),
  else tape rec; leaving SYNTH / PIANO lifts it. Knob contexts 43 (engine) and 44 (its LFO): 27 and 40 were taken;
  pkval 180. A first additive version (sines + envelopes) sounded fake and was replaced.
- MALLET, engine 12 (`apply_mallet.py`, `test_mallet.py`): the same modal voice, with the 10 struck instruments
  of the minichord (toy piano, kalimba, kalimba with buzz, handpan, steel pan, marimba, vibraphone, glockenspiel,
  bells, gamelan). Mode ratios / levels / decays / detunes in the tables mltr / mlta / mltd / mltt, filled when
  TYPE changes; mallet-post.pd: up to 2 body band-passes, buzz (part above 0.2, with noise, high-passed),
  vibraphone tremolo, soft limiter. Levels re-balanced so every type's single note peaks about 0.25 (the
  minichord evened them out with a tanh at its output). The TYPE row's name is printed by mallet-post on
  [s mlt-draw] (sent by synth.pd after the rows). Knob contexts 45 / 46 (pkval 188).
- PIANO and MALLET levels: a 6-note chord at full velocity stays under the clip (engine gains 0.25 / 0.2, soft
  limiter only above 0.8). A stolen voice (more keys than voices) fades out in 1.5 ms, its resonators are cleared
  ("set 0 0" to [biquad~]) and the strike comes 2 ms later: retuning a ringing resonator snapped.
- CPU: the resonators cost: 6 voices x 7 [biquad~] are about 9 of the PIANO's 14 ms per audio second on the Mac
  (FM 0.6, SUB 1.6). On the Organelle Pd goes from about 36 % idle to 46-50 % with full chords.
- SMPL loop points and playheads (`apply_smplloop.py`, `test_smplloop.py`): AUX + knobs 2 / 3 on SMPL = loop start /
  end, relative to START..END, snapped to zero crossings (same chunked searcher). Voice: the read position is a
  counter ([rpole~] of the time rate); idx = c while c < E, then ls + fmod(c - E, B); folded back by B every block
  once past E + B (precision on long notes). Playheads: each SMPL page frame sends `smp-ph-ask`, sounding voices
  answer `smp-ph <index>`; the page asks for another frame (`smp-phd`) while a voice sounds and for 6 frames after
  any note (the first frame can come before the voice has faded in). Knob context 42 (pkval 172): knob 1 = synth
  volume, its raw value is written into both pickup slots (52 and 168).
- SMPL time-stretch (`apply_smplstretch.py`, `test_smplstretch.py`): knob 4 is MODE one / str / s+lp / loop
  (old LOOP off = one, on = loop). Stretch reads the sample at its own speed and two 50 ms grains (Hann, half a
  grain apart) re-read it at the note's pitch: idx = position + grain phase x (pitch - 1) x 2205. Without stretch
  the offset is 0 and the two heads sum to the old single read. Pure tones can drift up to +-20 Hz (grain phase).
- SMPL page lighter (`apply_smplfast.py`): one baseline line for the flat bars, only taller bars as FillAreas, and
  ~7 frames/s while SMPL is the engine: ~1200 -> ~370 OLED messages/s while a knob turns.
- SMPL live view while recording: only the bar just measured is drawn (3 messages every 100 ms) instead of the
  whole SYNTH page (~60): from 610 to 30 OLED messages/s (`apply_smplive.py`).
- Auto-start sampling (`apply_autorec.py`): AUX+E5 (input) arms recording (badge ARM); it starts when the signal
  goes over 0.03, with a 15 ms pre-roll (`delwrite~`/`delread~`). Pressing again while armed cancels. AUX+F5
  (Nastro's own output) starts at once. Table resize / clear happen when arming, not at the onset.

- Synth LFO, one per engine (`apply_lfo.py`, `test_lfo.py`, `test_lfoproj.py`): AUX + D5 (key 74) on SYNTH toggles
  the LFO page (`syn-lfo-page`; leaving SYNTH closes it); knobs go to `<engine>-lfo-knob` = TYPE / RATE / AMT /
  DEST, stored in the engine and sent as `lfo-cfg` while it is active. `synth-lfo.pd`: P1..P4 = offsets
  `syn-lfo-mod eng param off` every 30 ms (each engine: value = clip(knob + off), the old parameter gets 0 back
  when engine / dest / type change); VOL and PITCH work on the engines' bus: engines `throw~ synth-eng`,
  synth-lfo applies a 12 ms modulated delay (vibrato, depth ms = AMT x 0.0293 / (2 pi rate), max 10) cross-faded
  with the dry signal, then the tremolo gain, and throws `synth-bus` (drums / monitor untouched).
  `synth-lfo-osc.pd` (own `switch~`, on only when TYPE is not off): phasor~ shapes, samphold~ noise (rand),
  two lop~ (drift), env~ of the input (env). Screen: modulated row label inverted (`syn-lfo-p`), redraw at most
  10/s while a row moves. Pickup contexts 29..39 (= 29 + engine id): pkval / pkpick 160. Old projects (116 values):
  Pd's array read repeats the last value into the missing slots, so "all LFO slots == pkval[115]" -> defaults.
- LED blinks while recording (`apply_recblink.py`, `test_recblink.py`): tape, sampler, drum sampling, album;
  250 ms off / on in the current colour (white while frozen).

## Mix and effects
- Limiter on the master (`apply_limiter.py`): per-block peak (`tabsend~` + `array max`), threshold 0.89, instant
  attack, ~150 ms release, final `clip~`. No added latency. Metronome and tape input are outside it.
- Master compressor (`apply_comp.py`, `test_comp.py`): MIX page 4 MASTER, COMP amount (threshold -2..-30 dBFS RMS,
  ratio 4:1, auto make-up up to +8 dB) and SPEED (attack 5–50 ms, release 50–800 ms). Feed-forward: `env~ 1024 128`
  on (L+R)/2 -> gain -> `line~`, before the limiter; off = no control work. GR shown live. Pickup ctx 22.
- Reverb (`genrev.py` → `reverb.pd`, `apply_reverb.py`): pre-delay (`vd~`) → 4 series allpasses → 8-line FDN
  (31.7–73.7 ms, Hadamard butterflies), per-line `lop~` and decay gain (10^(-3L/T60)/sqrt 8), 2 modulated lines.
  AUX + knobs on the FX page: DEC (T60 0.4–12 s), TONE (1.5–12 kHz), PRE (0–120 ms), MOD (ctx 16). `switch~`: on
  when REV > 0, off T60 + 0.5 s after REV goes to 0. `test_reverb.py`.
- Track DJ filters (`apply_trackfilter.py`, `test_trackfilter.py`): MIX page 3 FILTER, knob k = track k, centre
  off (dead zone 0.47–0.53), left LP 18 kHz–80 Hz, right HP 20 Hz–8 kHz, AUX = resonance. One `biquad~` per track
  after its level (RBJ coefficients computed in control only when a knob moves; off = `0 0 1 0 0`). Pickup ctx
  20 / 21 (`pkval` 88).
- Output meter (`genmeter.py` → `meter.pd`, `apply_meter.py`): title row of the MIX level page, L and R, 12
  segments -30..0 dBFS (`env~` after limiter and mute), falls one segment per frame, LIM light. 10 fps, only
  changed segments are drawn; `mt-reset` when the page clears the screen.

## Sequencers (SEQ mode, AUX+E cycles TEMPO → STEP → TOMBOLA → ENDLESS → ARP)
- TOMBOLA (`gentomb.py` → `tomb.pd`, `apply_tomb.py`): spinning polygon (3–8 sides) with up to 8 balls; each key
  throws a ball carrying its note, a wall hit plays it (velocity from the impact) on the active instrument via
  `seq-notes`. Knobs (ctx 15): spin, gravity, bounce, sides. AUX+A# removes the last ball, AUX+B all, AUX+C5
  pause. Plays only while its page is shown. Physics one ball per 3.75 ms slot; per ball: move, sector, best of 3
  walls (corners), bounce with the wall's push. Screen ~11 fps, text only on change. `test_tomb.py`.
- ENDLESS (`genendl.py` → `endl.pd`, `apply_endl.py`): stopped, every key appends a note (max 64), AUX+A# a rest,
  AUX+B clears; AUX+C5 starts/stops. Runs with the tape clock (tick16) forever; a key while running transposes
  relative to the first note. Knobs (ctx 17): RATE 1/4–1/32, GATE, DIRECTION (>> << <> ??), PROB. Saved with the
  project (`p<N>-endn.txt`, `p<N>-endp.txt`). Full redraw only on change, the playhead moves by inverting 2
  columns. `test_endl.py`.

## Projects
- Nastro starts empty (project 0: no files, so all defaults). "+ NEW" loads project 0 (resets everything,
  TOMBOLA balls included). A project is loaded only when chosen from the list. Saving project 0 (AUX+A or
  SAVE NEW) gives it the first free number (`apply_projnew.py`, `test_startempty.py`).
- Saving / loading blocks Pd while the tape WAVs are written / read: before it the tape stops, synth notes are
  released, the output fades out (40 ms); it fades back in afterwards (`apply_savemute.py`).

- TOMBOLA leaving its page (`apply_tombleave.py`): the page flag fanned out to a redraw request and to the page
  gates; when the request went first, one last tombola frame was drawn over the new page (half tombola, half
  the new page). A trigger now closes the gates first.

## Arpeggiator (`genarp.py` → `arp.pd`; `apply_arp.py`, `test_arp.py`)
- 5th SEQ page (seq-page 4, AUX+E cycles 5 pages). Held keys: tables `arpm` (128, membership), `arpo` (press order,
  compacted on release), `arps` (sorted, rebuilt by a 128-step scan on every change); count `arpc`. A step plays
  note = base[q % arpc] + 12 * int(q / arpc), q from the position and MODE over arpc x octaves positions.
- Clock: tick16 while the tape plays; otherwise an internal metro (beat / 4), first tick 20 ms after the first key.
  1/8T, 1/16T and 1/32 add steps with two [delay]s. PROB = random 100 < prob. Output through `seq-notes`.
- main.pd: on the ARP page (`arpcap`) the keys' note-ons do not reach the instrument; releases always pass.
- AUX + C5 = HOLD (STEP's AUX + C5, start STEP + tape from any page, is ignored on this page), AUX + B = clear.
- Knob contexts 40 (ARP) and 41 (ARP + AUX, PROB): pkval / pkpick 168. Projects with 160 values: Pd repeats the
  last value into slots 160..167, all equal -> defaults.

## Album (`genalbum.py` → `album.pd`; `apply_album.py`, `apply_albumview.py`, `test_album.py`, `test_albumview.py`)
- AUX + A5 (key 81) toggles: `writesf~ 2` (24-bit) of `s~ alb-L / alb-R`, tapped in master.pd after the limiter
  and the mute. Files `album-N.wav` next to the patch, counter in `album.txt` (table `albn`). The tape is rewound
  and started if stopped; stopping the tape closes the album. `album-rec` drives the LED blink and the TAPE `ALB`.
- Waveform: while recording, env~ 4096 -> amplitude -> `albpk` (up to 40000 peaks); at the stop 42 bars + length
  + highest bar -> `albw` -> `album-N.txt`. Viewer: PROJECTS menu entry 8 "ALBUMS >" opens menu context 2
  (rows `0 0` BACK, `9 k` album k, built by album.pd on `alb-menu`); project.pd lets album.pd draw the page
  (`alb-draw`). Play = `readsf~ 2` to outL/outR from a start point (`alb-go k onset`), position = start + [timer];
  AUX + C#5 / D#5 jump 5 s; redraw 4/s while playing (`alb-dirty`).
- expr variables are written without '-' (albplay, albsel ...): in expr `alb-play` means alb minus play.

## OLED mirror (`genmirror.py` → `mirror.pd`, menu item in `apply_mirrormenu.py`)
Off at start. PROJECTS menu → "SCREEN TO MAC: OFF/ON". The computer's IP address is in `mirror.txt` next to the
patch (e.g. `192.168.1.114;`); missing file: NO-MIRROR.TXT. Every OLED command (and the LED) goes out by UDP on
port 9123. On the computer: `OLED_BIND=0.0.0.0 python3 oled-sim.py`, open http://localhost:8123 and record the
window.
