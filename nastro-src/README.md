# Nastro – sources

The `.pd` files in `../Nastro` are generated by these scripts. Edit the scripts, not the `.pd` files.

    python3 gen.py ../Nastro                 # regenerate the whole patch (main.pd + modules)
    python3 gensim.py ../Nastro              # regenerate mac-sim.pd (Mac simulator)
    python3 makekit.py ../Nastro/drums.wav   # regenerate the drum kit

`gen.py` runs the other `gen*.py` (tape, screen, mix, tempo, drum, tapemap, synth, seq, smpl, proj, tapeedit,
tomb, rev, meter, endl, mirror). The `apply_*.py` scripts are the history of changes already applied to the
generators (each keeps a `*.pre-<name>` backup when it runs).

Target: Organelle 1, OS 4.0, Pd 0.49, single-core ARM, Pd started with `-audiobuf 6`.
Rules learned on the device: avoid control-rate bursts longer than ~2 ms per block (split long loops across
scheduler ticks), redraw the OLED only when something changes, keep the OLED under a few hundred messages/s.

## Review tools
- `python3 review.py ../Nastro`: sends/receives without a counterpart, connections into `[r]`, `[delay]` fed with
  floats, `expr` functions missing in Pd 0.49, orphan objects, signal objects per patch.
- `python3 review_order.py ../Nastro`: outlets feeding a cold inlet and a hot path that reaches it (order bugs).
- `python3 errscan.py test_X.py`: runs a test and reports every unexpected Pd error.

**Pd pitfalls met so far**
- Pd 0.49 `expr` has no `mtof()` (convert with the `[mtof]` object first). Available functions: the `ex_*`
  names in the device binary.
- A multi-outlet `expr` evaluates each outlet only when it sends it (right to left): if one outlet writes a table
  the others read, collect everything in a `[pack]` first and write afterwards.
- `[r name]` has no inlet: to merge two receives, connect both to the destination.
- A float into the left inlet of `[delay]` sets its time and starts it.
- Commas in comments (`#X text`) break the patch.

## Tape
- 4 tracks x 60 s, precise playhead (`rpole~` counter + per-block integer onset).
- Loop wrap crossfade: a second head per track keeps playing past the jump and fades out in 5 ms while the main
  head fades in (`apply_xfade.py`, `test_loopclick.py`). Only the output is crossfaded; overdub reads the main head.
- Loop recording seam fix (`apply_loopseam.py`, `test_loopseam.py`): the wrap is handled per 64-sample block, so
  each pass wrote up to 65 samples past the loop end and left a seam at the loop start. While recording a loop,
  the samples written past the end are moved to the start (re-mixed for overdub) and the area after the end is
  restored from a copy saved when recording starts / the loop end moves.
- Punch-in/out fades (`apply_punchfade.py`, `test_punch.py`): the writer blends old → new over 8 ms at rec start
  and back at rec stop, and keeps running until the fade-out is done, so punches leave no step on tape. The gain
  of the last block is kept in `pgbuf` so the seam fix stays exact when a fade crosses the loop end.
- Key timing on the device (`apply_keydefer.py`, `test_devorder.py`): the Organelle delivers keys after a DSP tick
  but before that tick's `[bang~]` updates the tape position, so rec started the writer one block behind the
  head (a 64-sample silent gap at every restart). Tape keys, footswitch, navigation and track changes now go
  through `[pipe 0]`, which runs them after the position update. Mac batch tests can't reproduce the device order.
- Sample-accurate wrap (`apply_xfadeauto.py`): just before the head reaches a loop edge each track is checked. If
  the loop start continues the audio at the end (recorded in loop mode), its read index wraps per sample
  (`expr~` offset) with no crossfade; otherwise it reads past the end and crossfades as before. The 3 samples
  `tabread4~` reads across the edge are temporarily replaced with the continuation and restored after the wrap.
- Lanes under the reels update 4x/s while recording (was 10x/s with a full rebuild each time).
- Speed, knob 1 in TAPE: 7 octave steps (-2 -1 -0.5 0 0.5 1 2) spread over the knob travel; with AUX held it is
  continuous (-2..2, magnets at 1 / 0 / -1). Global for all tracks. Recording forces 1x.

### Tape editing (`gentapeedit.py` → `tapeedit.pd`)
Encoder press in TAPE → menu `EDIT-T n`: CUT, COPY, PASTE, REVERSE, CLEAR, DUPLICATE, UNDO on the selected track,
over the loop region (when looping) or the current bar. Copies run 4096 samples per tick (`array get/set`, the
table name goes to the right inlet: Pd 0.49 has no `set` message). Reverse runs in real time with an `rpole~`
counter + `tabwrite~` (block-aligned; `vline~` was ~80 samples off).
- UNDO: before every change the touched region is copied into `te-undo`; UNDO swaps it with the tape (again =
  redo). Recording or loading a project forgets it (`apply_undo.py`).
- All tracks: menu item "MODE: 1 TRACK / ALL" (op 8). With ALL every op 1..6 runs for tracks 1..4 in sequence
  (state in table `teseq`), reusing the single-track code: clipboard and undo have 4 slots (offset
  (k-1)*length), the region is computed once, DUPLICATE moves the loop only after the last track
  (`apply_editall.py`, `apply_editall_menu.py`, `test_editall.py`).

## Synth engines
FM, SUB, PLUK, PAD, SMPL, AIR, GLASS. AUX+C again in SYNTH = next engine. Every voice switches its own DSP on at
a note and off when its sound has ended (`switch~`, PLUK `switch~ 16`; `apply_voiceswitch.py`): about -42% DSP idle.
- SUB ADSR (`apply_subadsr.py`, `test_subadsr.py`): AUX + knobs 2..4 on SUB = ATTACK (1–3000 ms), DECAY/RELEASE
  (10–5000 ms), SUSTAIN; knob 1 stays the synth volume. Amp ADSR (`vline~`), filter envelope attack + decay to 0.
  Defaults = the old sound (5 ms / ~400 ms / 100 %). Pickup ctx 13 slots 2..4.
- AIR (`apply_ambient.py`): noise through 2 band-passes (note + octave, `vcf~`), Q from breath (2) to whistle (60)
  with sqrt(Q) make-up gain, slow random LFO per voice on pitch and level. Knobs ATK REL Q MOVE (pickup ctx 18).
- GLASS: 4 partials (harmonic 1 2 3 4 <-> bell 1 2.76 5.4 8.93), shorter decay for higher partials, 2 detuned
  twins for beating, 6 voices, rings through note-off. Knobs DECAY BRITE INHAR BEAT (ctx 19). `test_ambient.py`.
- SMPL live view while recording: only the bar just measured is drawn (3 messages every 100 ms) instead of the
  whole SYNTH page (~60): from 610 to 30 OLED messages/s (`apply_smplive.py`).
- Auto-start sampling (`apply_autorec.py`): AUX+E5 (input) arms recording (badge ARM); it starts when the signal
  goes over 0.03, with a 15 ms pre-roll (`delwrite~`/`delread~`). Pressing again while armed cancels. AUX+F5
  (Nastro's own output) starts at once. Table resize / clear happen when arming, not at the onset.

## Mix and effects
- Limiter on the master (`apply_limiter.py`): per-block peak (`tabsend~` + `array max`), threshold 0.89, instant
  attack, ~150 ms release, final `clip~`. No added latency. Metronome and tape input are outside it.
- Master compressor (`apply_comp.py`, `test_comp.py`): MIX page 4 MASTER, COMP amount (threshold -2..-30 dBFS RMS,
  ratio 4:1, auto make-up up to +8 dB) and SPEED (attack 5–50 ms, release 50–800 ms). Feed-forward: `env~ 1024 128`
  on (L+R)/2 -> gain -> `line~`, before the limiter; off = no control work. GR shown live. Pickup ctx 22 (`pkval` 92).
- Reverb (`genrev.py` → `reverb.pd`, `apply_reverb.py`): pre-delay (`vd~`) → 4 series allpasses → 8-line FDN
  (31.7–73.7 ms, Hadamard butterflies), per-line `lop~` and decay gain (10^(-3L/T60)/sqrt 8), 2 modulated lines.
  AUX + knobs on the FX page: DEC (T60 0.4–12 s), TONE (1.5–12 kHz), PRE (0–120 ms), MOD (ctx 16). `switch~`: on
  when REV > 0, off T60 + 0.5 s after REV goes to 0. `test_reverb.py`.
- Track DJ filters (`apply_trackfilter.py`, `test_trackfilter.py`): MIX page 3 FILTER, knob k = track k, centre
  off (dead zone 0.47–0.53), left LP 18 kHz–80 Hz, right HP 20 Hz–8 kHz, AUX = resonance. One `biquad~` per track
  after its level (RBJ coefficients computed in control only when a knob moves; off = `0 0 1 0 0`). Pickup ctx
  20 / 21 (`pkval` 88).
- Output meter (`genmeter.py` → `meter.pd`, `apply_meter.py`): title row of the MIX level page, L and R, 12
  segments -30..0 dBFS (`env~` after limiter and mute), falls one segment per frame, LIM light. 10 fps, only
  changed segments are drawn; `mt-reset` when the page clears the screen.

## Sequencers (SEQ mode, AUX+E cycles TEMPO → STEP → TOMBOLA → ENDLESS)
- TOMBOLA (`gentomb.py` → `tomb.pd`, `apply_tomb.py`): spinning polygon (3–8 sides) with up to 8 balls; each key
  throws a ball carrying its note, a wall hit plays it (velocity from the impact) on the active instrument via
  `seq-notes`. Knobs (ctx 15): spin, gravity, bounce, sides. AUX+A# removes the last ball, AUX+B all, AUX+C5
  pause. Plays only while its page is shown. Physics one ball per 3.75 ms slot; per ball: move, sector, best of 3
  walls (corners), bounce with the wall's push. Screen ~11 fps, text only on change. `test_tomb.py`.
- ENDLESS (`genendl.py` → `endl.pd`, `apply_endl.py`): stopped, every key appends a note (max 64), AUX+A# a rest,
  AUX+B clears; AUX+C5 starts/stops. Runs with the tape clock (tick16) forever; a key while running transposes
  relative to the first note. Knobs (ctx 17): RATE 1/4–1/32, GATE, DIRECTION (>> << <> ??), PROB. Saved with the
  project (`p<N>-endn.txt`, `p<N>-endp.txt`). Full redraw only on change, the playhead moves by inverting 2
  columns. `test_endl.py`.

## Projects
- Nastro starts empty (project 0: no files, so all defaults). "+ NEW" loads project 0 (resets everything,
  TOMBOLA balls included). A project is loaded only when chosen from the list. Saving project 0 (AUX+A or
  SAVE NEW) gives it the first free number (`apply_projnew.py`, `test_startempty.py`).
- Saving / loading blocks Pd while the tape WAVs are written / read: before it the tape stops, synth notes are
  released, the output fades out (40 ms); it fades back in afterwards (`apply_savemute.py`).

## OLED mirror (`genmirror.py` → `mirror.pd`, menu item in `apply_mirrormenu.py`)
Off at start. PROJECTS menu → "SCREEN TO MAC: OFF/ON". The computer's IP address is in `mirror.txt` next to the
patch (e.g. `192.168.1.114;`); missing file: NO-MIRROR.TXT. Every OLED command (and the LED) goes out by UDP on
port 9123. On the computer: `OLED_BIND=0.0.0.0 python3 oled-sim.py`, open http://localhost:8123 and record the
window.

## On-screen language
All on-screen text is English (`apply_english.py`).

## Future ideas (agreed with the user, for later)
- **Tape recording at speeds other than 1x** (like the OP-1: record at half speed, play at 1x one octave up).
  Today rec forces 1x because `tabwrite~` only writes forward. Plan: record into a temporary buffer at 1x and, at
  stop (or each loop pass), resample it to the tape speed and mix it onto the track (overdub), chunked over many
  blocks so the Organelle does not glitch. Reverse recording too.
- Undo of the last recording in a DRUM key / restore the key's base sound.
- Fine START/END adjustment (e.g. AUX + knob = 20x smaller steps).
- More tape editing (free selection beyond loop/bar, undo a recording), MIDI in/clock, project names, save only
  the tape tracks that changed.

Warning: do not run a second Pd `-batch` on the Organelle while the patch is running (it froze / rebooted it).
